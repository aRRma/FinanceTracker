# Отложенное, риски и открытые вопросы

Что сознательно не делается и во что обойдётся возврат, чем рискуем, что ещё не решено. Почему решено именно так — в [adr/](adr/).

| Отложено | Стоимость реализации позже |
|---|---|
| Внешняя аутентификация | Добавление владельца строк в таблицы сервера с заполнением существующих данных. Клиент не затрагивается |
| Чистка надгробий | Фоновая задача. Требует одновременного введения порога отставания устройства |
| Полная пересинхронизация | Новый эндпоинт и таблица устройств на сервере |
| Теги | Связь многие-ко-многим. Рекомендуемая реализация — отдельная сущность тега и массив ссылок в операции |
| Импорт | Поле внешнего идентификатора зарезервировано. Требует пакетной отправки при первой синхронизации. Разовый перенос из Wallet функцией импорта не считается и полем не пользуется (ADR-0014) |
| Поддержка iOS | Выбранная платформа не создаёт препятствий |
| Сумма операции в рублях, замороженная на дату записи | Колонка добавляется миграцией, но прошлым валютным операциям курс взять неоткуда: потребуется внешний источник котировок либо они останутся вне отчёта. Сейчас валютная операция в отчёт не входит вовсе, и цена решения — владелец валютного счёта своих трат в отчёте не видит |
| Ручной порядок групп и подкатегорий | Колонка порядка и перетаскивание, как у счетов. Сейчас справочник сортируется по имени, служебная группа в конце |
| История изменения лимита бюджета | Вместе с бюджетами. Без неё правка лимита переписывает и прошлые месяцы: они начинают считаться по нынешнему значению |
| Переключение универсальности у существующей группы | Включение безопасно всегда, выключение требует межтабличной проверки с чтением данных (ADR-0013) |

**Не подлежит отложению.** Схема идентификаторов и детерминированные ключи стартового набора (ADR-0002, ADR-0006): после накопления данных их меняет только полная миграция с перепрошивкой всех ссылок.

| Риск | Оценка | Смягчение |
|---|---|---|
| Отсутствие выгрузки данных при единственном устройстве | Средняя вероятность, высокий ущерб | Резервное копирование перед миграцией закрывает часть риска. Полностью закрывается выгрузкой в файл |
| Расхождение данных между устройствами без внешних признаков (вне MVP) | Средняя вероятность, высокий ущерб | Сценарные тесты третьего этапа, сверка контрольной суммой в дальнейшем |
| Изменение требований внешних провайдеров аутентификации (вне MVP) | Высокая вероятность, низкий ущерб | Сверяться с актуальной документацией на момент реализации |

Закрытые риски и вопросы — отставание MAUI от платформы, целевая версия Android (SYS-01), состав значков (`data/icons.json`), отчёт в MVP, недооценка трудоёмкости второго этапа (этап закрыт) — из таблиц убраны: решение записано там, где оно действует.

| Открытый вопрос (вне MVP) | Что известно |
|---|---|
| Размер пачки синхронизации | Ориентировочно 500 строк, уточняется по результатам первой выгрузки |
| Номер версии протокола | Реакция на несовпадение версий не задана; решить до написания DTO |
