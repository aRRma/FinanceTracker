# Отложенное, риски и открытые вопросы

Что сознательно не делается и во что обойдётся возврат, чем рискуем, что ещё не решено.

| Отложено | Стоимость реализации позже |
|---|---|
| Внешняя аутентификация | Добавление владельца строк в таблицы сервера с заполнением существующих данных. Клиент не затрагивается |
| Чистка надгробий | Фоновая задача. Требует одновременного введения порога отставания устройства |
| Полная пересинхронизация | Новый эндпоинт и таблица устройств на сервере |
| Теги | Связь многие-ко-многим. Рекомендуемая реализация — отдельная сущность тега и массив ссылок в операции |
| Аналитика | Схема готова. Требует решения о сворачивании подкатегорий в группы |
| Импорт | Поле внешнего идентификатора зарезервировано. Требует пакетной отправки при первой синхронизации |
| Поддержка iOS | Выбранная платформа не создаёт препятствий |

**Не подлежит отложению.** Схема идентификаторов и детерминированные ключи пресета. Изменение после накопления данных возможно только полной миграцией с перепрошивкой всех ссылок.

| Риск | Оценка | Смягчение |
|---|---|---|
| Отсутствие отчётов в MVP снижает мотивацию довести проект до третьего этапа | Высокая вероятность, высокий ущерб | Реализовать один отчёт о расходах по категориям в конце первого этапа |
| Отсутствие выгрузки данных при единственном устройстве | Средняя вероятность, высокий ущерб | Резервное копирование перед миграцией закрывает часть риска. Полностью закрывается выгрузкой в файл |
| Недооценка трудоёмкости второго этапа | Высокая вероятность, средний ущерб | Закладывать запас, не планировать на этап фиксированный срок |
| Расхождение данных между устройствами без внешних признаков | Средняя вероятность, высокий ущерб | Сценарные тесты третьего этапа, сверка контрольной суммой в дальнейшем |
| Отставание версии MAUI от релиза платформы | Средняя вероятность, низкий ущерб | Проверить доступность всей связки до начала работ |
| Изменение требований внешних провайдеров аутентификации | Высокая вероятность, низкий ущерб | Сверяться с актуальной документацией на момент реализации |
