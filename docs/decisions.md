# Отложенное, риски и открытые вопросы

Что сознательно не делается и во что обойдётся возврат, чем рискуем, что ещё не решено. Почему решено именно так — в [adr/](adr/); что вне MVP — в [requirements/01-scope.md](requirements/01-scope.md).

| Отложено | Стоимость реализации позже |
|---|---|
| Внешняя аутентификация | Добавление владельца строк в таблицы сервера с заполнением существующих данных. Клиент не затрагивается |
| Чистка надгробий | Фоновая задача. Требует одновременного введения порога отставания устройства |
| Полная пересинхронизация | Новый эндпоинт и таблица устройств на сервере |
| Теги | Связь многие-ко-многим: отдельная сущность тега и ссылки на неё из операции |
| Импорт | Поле внешнего идентификатора зарезервировано, индекс по нему заводится вместе с повторяемым импортом. Требует пакетной отправки при первой синхронизации. Разовый перенос из Wallet импортом не считается (ADR-0014) |
| Поддержка iOS | Прикладной слой нейтрален, но платформенную часть придётся написать заново: хранилище ПИН-кода и заслонку защиты входа, часы с учётом сна, сохранение файла, историю завершений и перехват сбоев |
| Сумма операции в рублях, замороженная на дату записи | Колонка добавляется миграцией, но прошлым валютным операциям курс взять неоткуда: потребуется внешний источник котировок либо они останутся вне отчёта. Сейчас валютная операция входит только в отчёт по счетам своей валюты |
| Ручной порядок групп и подкатегорий | Колонка порядка и перетаскивание, как у счетов. Сейчас справочник сортируется по имени; служебная группа — последней среди групп, «Прочее» — последним в своей группе |
| История изменения лимита бюджета | Вместе с бюджетами. Без неё правка лимита переписывает и прошлые месяцы: они начинают считаться по нынешнему значению |
| Переключение универсальности у существующей группы | Включение безопасно всегда, выключение требует межтабличной проверки с чтением данных (ADR-0013) |
| Уникальные индексы на имена | Правило домена сравнивает имена без учёта регистра, а встроенное сравнение SQLite кириллицу не сворачивает: понадобится колонка со свёрнутым именем, заполняемая при каждой записи. Колонка и индекс добавляются миграцией |
| Внешние ключи и ограничения-проверки в базе | Ловили бы ссылку в никуда и правку мимо приложения, но дублируют доменные правила и расходятся с ними молча; внешние ключи вдобавок отвергнут записи обмена, приехавшие не по порядку. Включаются миграцией, ключи — с правкой порядка вставки |
| Настройка хранения по замеру | Сужение индексов по счёту зачисления и по категории до заполненных строк (колонки пусты у большинства операций), `PRAGMA synchronous=NORMAL` рядом с WAL, `PRAGMA optimize` для статистики планировщика. Каждая правка — строка конфигурации и миграция, но делается только по плану запроса или замеру: без цифры выигрыша риск объяснять нечем |
| Доступность | Значки и поля без текста озвучиваются читалкой экрана, но ни требования, ни проверки на это нет; масштаб шрифта и крупный текст не проверялись |

Схему идентификаторов и ключи стартового набора отложить нельзя: после накопления данных их меняет только полная миграция с перепрошивкой всех ссылок (ADR-0002, ADR-0006).

| Риск | Оценка | Смягчение |
|---|---|---|
| Копия данных вне телефона есть, только если выгрузку сохранили, а файл выгрузки не зашифрован (ADR-0015, ADR-0017) | Средняя вероятность, высокий ущерб | Сохранять выгрузку после крупных правок; хранить файл там же, где прочие личные документы |
| Забытый ПИН-код не сбрасывается: без выгрузки данные потеряны (ADR-0017) | Низкая вероятность, высокий ущерб | Выгрузка; защиту пользователь включает сам |
| Расхождение данных между устройствами без внешних признаков (вне MVP) | Средняя вероятность, высокий ущерб | Сценарные тесты обмена, сверка контрольной суммой в дальнейшем |

| Открытый вопрос (вне MVP) | Что известно |
|---|---|
| Размер пачки синхронизации | Ориентировочно 500 строк, уточняется по результатам первой отправки |
| Номер версии протокола | Реакция на несовпадение версий не задана; решить до написания DTO |
| Поле `synced_at_utc` рядом с очередью отправки | Заведено в схеме, кодом не читается; останется ли оно рядом с очередью (SYN-03) — решить вместе с обменом |
