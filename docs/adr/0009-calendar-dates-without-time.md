# Календарные даты хранятся без времени и часового пояса

Дата операции и дата открытия счёта — `DateOnly`, суффикс `_on`, никаких преобразований (NFR-12). Моменты времени — `DateTimeOffset` в UTC, суффикс `_at_utc` (NFR-11). «Сегодня» — локальная дата пользователя, а не `UtcNow.Date` (NFR-13). Часовой пояс хранится идентификатором зоны, а не числовым смещением (NFR-14). Баланс считается по всем неудалённым операциям без условия «не позже сегодняшней даты» (FR-BAL-01).

**Дата как момент в UTC** отвергнута: операция, записанная вечером по местному времени, уехала бы на сутки и сломала границы месяца в отчёте. **`UtcNow.Date`** отвергнут по той же причине с другой стороны. **Смещение вместо зоны** отвергнуто: смещение перестаёт соответствовать зоне на переходе на летнее время. **Фильтр «не позже сегодня» в балансе** отвергнут: даты в будущем и так запрещены при вводе (INV-09), а фильтр отсекал бы только операции с устройства в поясе восточнее и разводил балансы на сутки, когда появится обмен.

Цена — два разных типа для времени в одной модели и правило, которое приходится помнить: дата никогда не проходит через конвертацию зон.
