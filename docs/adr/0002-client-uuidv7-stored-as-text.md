# Ключи — UUIDv7 с клиента, в SQLite хранятся текстом

Идентификаторы всех сущностей генерирует клиент как UUIDv7 (`ValueGeneratedNever()`), в SQLite они хранятся `TEXT` в каноническом виде. Ключ участвует в сортировке ленты как разрыв ничьей: внутри одного дня операции идут по `created_at_utc`, а при равных значениях — по ключу (FR-LED-02), поэтому порядок совпадает на любом устройстве. Монотонность UUIDv7 даёт локальность вставок в индекс: новые строки ложатся в конец B-дерева, а не расщепляют страницы.

**Серверные автоинкременты** отвергнуты сразу: записи создаются офлайн, и ключ обязан существовать до того, как сервер о нём узнает. **Двоичное хранение `Guid`** отвергнуто из-за порядка байтов: `Guid.ToByteArray()` без `bigEndian: true` переставляет байты, и это ломает и сравнение ключей, и локальность вставок — молча, без единой ошибки (TECH-01). **Сортировка только по времени создания** отвергнута: `created_at_utc` ставится часами устройства без коррекции и может совпасть у двух операций.

Схема идентификаторов после накопления данных возврату не подлежит: изменение означало бы полную миграцию с перепрошивкой всех ссылок.
