# Категории стартового набора: детерминированные ключи и фиксированная метка засева

Стартовые категории получают идентификаторы UUIDv5, выведенные из неизменяемого строкового ключа и `namespace` из `data/preset.json` (SEED-02). Засев проставляет всем строкам одну заведомо давнюю метку `updated_at_utc` — `seededAtUtc`, 2000 год (SEED-03). Сверка наличных — обычная операция в служебной подкатегории «Разница», по одной на расход и доход, исключённых из отчёта (SEED-06); отдельной функции сверки нет.

**Случайные ключи** отвергнуты: при установке на второе устройство каждая категория стартового набора оказалась бы новой сущностью, и обмен создал бы дубликаты всего набора. **Текущее время засева** отвергнуто: при переустановке или установке на новое устройство свежая метка оказалась бы новее пользовательских переименований и затёрла бы их при слиянии. **Функция сверки** отвергнута как преждевременная: она добавляется позже без изменения схемы, потому что лишь создаёт обычную операцию в уже существующей категории; цена — разницу пользователь считает сам.

Следствие, которое нельзя нарушить: ключи категорий и `namespace` в `data/preset.json` не меняются никогда. Правка ключа необратима даже с историей в git — из него выведен идентификатор, на который ссылаются операции.
