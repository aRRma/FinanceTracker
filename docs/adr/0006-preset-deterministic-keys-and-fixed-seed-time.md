# Категории стартового набора: детерминированные ключи и давняя метка времени

Стартовые категории получают идентификаторы UUIDv5, выведенные из неизменяемого строкового ключа и `namespace` из `data/preset.json` (SEED-02). Инициализация базы проставляет всем строкам одну заведомо давнюю метку `updated_at_utc` — `seededAtUtc`, 2000 год (SEED-03). Сверка наличных — обычная операция в служебной подкатегории «Разница», исключённой из отчёта (SEED-06); отдельной функции сверки нет. ~~Подкатегорий было две, расходная и доходная~~ — слиты в одну вместе с появлением универсальных групп (ADR-0013).

**Случайные ключи** отвергнуты: при установке на второе устройство каждая категория стартового набора оказалась бы новой сущностью, и обмен создал бы дубликаты всего набора. **Текущее время при инициализации** отвергнуто: при переустановке или установке на новое устройство свежая метка оказалась бы новее пользовательских переименований и затёрла бы их при слиянии. **Функция сверки** отвергнута как преждевременная: она добавляется позже без изменения схемы, потому что лишь создаёт обычную операцию в уже существующей категории; цена — разницу пользователь считает сам.

Следствие, которое нельзя нарушить: ключи категорий и `namespace` в `data/preset.json` не меняются никогда. Правка ключа необратима даже с историей в git — из него выведен идентификатор, на который ссылаются операции.

Набор пишется один раз за жизнь установки: новая версия набора доезжает только до свежей установки. Установленному приложению правку приносит миграция, если она нужна всем (как `MergeServiceGroups` в ADR-0013), — иначе пользователь сохраняет свои переименования и удаления.

«Не меняются» значит, что ключ не получает другого смысла, а не что строку нельзя убрать. Набор версии 2 (сентябрь 2026) убрал пять ключей первой версии, три из них переехали под новыми ключами (`docs/preset-rationale.md`, «Пересмотр под перенос истории»). Установки с первой версией их сохраняют; убранный ключ не переиспользуется никогда, поэтому будущий обмен не склеит разные статьи.
