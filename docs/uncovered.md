# Требования без сценария

Проверка покрытия (`tools/lint_docs.py`, L9) требует, чтобы каждое функциональное требование упоминалось хотя бы в одном сценарии из [use-cases.md](use-cases.md) либо было объяснено здесь.

Список не «долг», а решение: перечисленные требования сценария не требуют, и причина у каждого своя.

| Требование | Почему сценарий не нужен |
|---|---|
| FR-CAT-10 | Отображение значка в ленте и списках — свойство разметки, не действие пользователя |
| FR-BAL-07, FR-LED-06 | Пустые состояния. Показаны на экранах C-06 и C-03, шагов пользователя не содержат |
| FR-SET-04 | Экран «О программе». Открывается раз в жизни, поведение приложения не меняет |
| FR-CAT-11 | Отрицательное требование: удаления группы нет. Сценария на отсутствующее действие не бывает |
| FR-LED-05 | Правило отображения перевода в общей ленте. Проявляется внутри UC-06, отдельного повода открыть приложение не создаёт |
| FR-SET-01 | Часовой пояс берётся из системы; ручное переопределение — аварийный рычаг, а не сценарий |
| FR-SET-03 | Выбор темы оформления. Разовая настройка внешнего вида, поведение приложения не меняет |
| FR-BAL-06 | Отрицательный баланс допустим и ничем не сопровождается. Требование о том, что ничего не происходит |
| FR-CAT-03 | Переименование категории. Тривиальная правка поля, ветвлений не имеет |
| FR-CAT-04 | Перенос подкатегории в другую группу. Отдельного повода открыть приложение не создаёт, случается внутри разбора дерева |
| FR-CAT-07 | Засев стартового набора при первом запуске. Описан прозой в UC-01 и покрыт тестом пресета, пользовательских шагов не имеет |
| ~~FR-SET-02~~ | Отложено вместе с обменом |

Добавлять сюда требование, для которого сценарий просто не написан, — значит обманывать проверку. Если сценарий нужен, но его нет, место ему в [../PLAN.md](../PLAN.md), а не здесь.
