# Требования без сценария

Каждое функциональное требование упоминается в сценарии из [use-cases.md](use-cases.md) либо объяснено здесь — это сверяет `Finance.Docs.Tests`. Список — решение, а не долг: требование, для которого сценарий просто не написан, сюда не заносится, его место — в [../PLAN.md](../PLAN.md).

| Требование | Почему сценарий не нужен |
|---|---|
| FR-CAT-10 | Отображение значка в ленте и списках — свойство разметки, не действие пользователя |
| FR-CAT-11 | Отрицательное требование: удаления группы нет. Сценария на отсутствующее действие не бывает |
