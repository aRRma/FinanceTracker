# Требования без сценария

Проверка покрытия в `Finance.Docs.Tests` требует, чтобы каждое функциональное требование упоминалось хотя бы в одном сценарии из [use-cases.md](use-cases.md) либо было объяснено здесь.

Список не «долг», а решение: перечисленные требования сценария не требуют, и причина у каждого своя.

| Требование | Почему сценарий не нужен |
|---|---|
| FR-CAT-10 | Отображение значка в ленте и списках — свойство разметки, не действие пользователя |
| FR-CAT-11 | Отрицательное требование: удаления группы нет. Сценария на отсутствующее действие не бывает |

Добавлять сюда требование, для которого сценарий просто не написан, — значит обманывать проверку. Если сценарий нужен, но его нет, место ему в [../PLAN.md](../PLAN.md), а не здесь.
