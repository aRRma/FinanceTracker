# Функциональные требования

Что приложение умеет делать, по разделам интерфейса. Идентификаторы: `FR-ACC-*`, `FR-CAT-*`, `FR-TRX-*`, `FR-PAY-*`, `FR-BAL-*`, `FR-LED-*`, `FR-RPT-*`, `FR-SET-*`; отложенные вместе с обменом `FR-SYN-*` — в разделе «Синхронизация — отложено» ниже, общие требования обмена `SYN-*` — в [06-sync-deferred.md](06-sync-deferred.md).

## Счета

| FR-ACC-01 | Создание счёта с указанием наименования, типа, валюты, начального остатка и даты открытия. Остаток набирается клавиатурой суммы, как сумма операции, и бывает отрицательным — долг: минус первой клавишей. Подсказка в пустом названии своя у каждого типа счёта |
|---|---|
| FR-ACC-02 | Редактирование счёта с соблюдением INV-11 и INV-12. Карточка счёта открывается из справочника счетов и из ленты счёта — значком-карандашом у её названия |
| FR-ACC-03 | Ручное упорядочивание счетов перетаскиванием |
| FR-ACC-04 | Пометка счёта признаком «скрытый» |
| FR-ACC-05 | Удаление счёта без операций — из его карточки, после подтверждения (INV-35). Счёт с операциями не удаляется: попытка отвечает всплывающим сообщением, что его можно заблокировать (FR-ACC-06). Если карточку открыли из ленты счёта, после удаления приложение возвращается туда, откуда открыли ленту, а не в ленту удалённого счёта. ~~Удаление счёта не предусмотрено~~ — отменено: счёт, заведённый по ошибке, оставался бы навсегда |
| FR-ACC-06 | Блокировка счёта и обратное открытие — только у заведённого счёта: в карточке нового счёта переключателя нет, и новый счёт всегда открыт. Заблокированный счёт не показывается на главном экране, не входит в «доступно к тратам», не предлагается в выборе счёта и не подставляется как последний использованный; в справочнике счетов выделен в раздел «Заблокированные». Ленты, итоги дня и отчёт не меняются. Ненулевой баланс блокировке не мешает, но блокировка счёта с деньгами подтверждается отдельным вопросом с суммой остатка |

## Категории

| FR-CAT-01 | Создание группы с указанием вида |
|---|---|
| FR-CAT-02 | Создание подкатегории внутри группы |
| FR-CAT-03 | Переименование категории любого уровня |
| FR-CAT-04 | Перенос подкатегории в другую группу |
| FR-CAT-05 | Удаление подкатегории с переносом операций согласно INV-20 |
| FR-CAT-06 | Автоматическое создание подкатегории «Прочее» при создании группы (INV-18) |
| FR-CAT-07 | Наполнение стартовым набором категорий при первом запуске |
| FR-CAT-08 | Выбор значка категории из набора, зашитого в приложение. Значок задаётся на обоих уровнях |
| FR-CAT-09 | При создании подкатегории значок по умолчанию наследуется от группы и может быть изменён |
| FR-CAT-10 | Значок отображается в ленте операций, в списке категорий и при выборе категории |
| FR-CAT-11 | Удаление группы не предусмотрено в MVP. Опустевшие группы остаются в списке (INV-34) |
| FR-CAT-12 | В списке выбора подкатегории — отбор по набранным буквам названия. Это не поиск по операциям, который вынесен за MVP, а сокращение длинного списка |
| FR-CAT-13 | Над списком выбора подкатегории — панель самых частых подкатегорий того же вида с горизонтальной прокруткой. Частота — число операций за последние три месяца. В панели не больше восьми, служебная «Разница» в неё не попадает. При отборе по набранным буквам (FR-CAT-12) панель убирается |
| FR-CAT-14 | При создании группы задаётся ещё и универсальность: принимать операции обоих видов или только своего. Универсальная группа предлагается при выборе категории для операции любого вида: сначала идут группы вида операции, ниже отдельным подписанным разделом — универсальные группы другого вида. Как и вид, после создания не меняется |
| FR-CAT-15 | В списке выбора подкатегории «Прочее» стоит первой строкой раскрытой группы: им записывают трату без подробностей. Группа из одной подкатегории не раскрывается — касание выбирает её подкатегорию. Там, где группа не видна, — в поле формы и на панели частых — «Прочее» подписано с группой: «Еда · Прочее» |

## Операции

| FR-TRX-01 | Создание расхода: счёт, сумма, категория, дата, заметка |
|---|---|
| FR-TRX-02 | Создание дохода с тем же составом полей |
| FR-TRX-03 | Создание перевода: счёт списания, счёт зачисления, сумма; сумма зачисления запрашивается только при различающихся валютах |
| FR-TRX-04 | Редактирование операции с возможностью изменить вид |
| FR-TRX-05 | Удаление операции с обязательным подтверждением |
| FR-TRX-06 | Подстановка в форму создания последнего использованного счёта (из ленты счёта — этого счёта; последний удалён или заблокирован — первого открытого) и текущей локальной даты. Подставить нечего — открытых счетов нет: набранная сумма видна без знака валюты, поле счёта отмечено как обязательное и ведёт сразу в карточку нового счёта, а заведённый счёт встаёт в форму с набранным. Сохранение без счёта называет это всплывающим сообщением |
| FR-TRX-07 | Вид операции по умолчанию — расход |
| FR-TRX-08 | Категория не подставляется автоматически и выбирается каждый раз |
| FR-TRX-09 | Поле суммы принимает арифметическое выражение из четырёх действий, вычисляемое слева направо без приоритета; результат округляется до копеек. Итог показывает клавиша «=», сворачивая выражение в число; пока действие не закрыто, на месте итога подсказка про «=», а выражение стоит над ней. Сохранение с незакрытым действием записывает тот же итог, что показала бы «=»; недописанное выражение («100+») не сохраняется — форма просит дописать сумму |
| FR-TRX-10 | Выбор даты: календарь с быстрыми «Сегодня» и «Вчера». Даты в будущем и раньше открытия счёта недоступны для выбора. Смена счёта, после которой выбранная дата оказалась раньше его открытия, переносит дату на день открытия и сообщает об этом всплывающим сообщением |
| FR-TRX-11 | Ярлыки на значке приложения: «Расход», «Доход», «Перевод» открывают форму новой операции с уже выбранным видом. Форма открывается поверх главного экрана, «назад» с неё ведёт на балансы |

## Места

| FR-PAY-01 | Указание места при создании и редактировании операции |
|---|---|
| FR-PAY-02 | Ввод места с подстановкой ранее использованных значений по мере набора |
| FR-PAY-03 | Создание нового места прямо из формы операции, без перехода в справочник |
| FR-PAY-04 | Переименование места. Изменение отражается во всех операциях без их правки |
| FR-PAY-05 | Удаление места. Строки операций не изменяются: операции с удалённым местом отображаются как операции без места, в подсказках оно не предлагается |
| FR-PAY-06 | Порядок в подсказках определяется частотой использования |
| FR-PAY-07 | Справочники показывают счётчики: у места — число операций и подкатегория, в которой оно встречается чаще всего; у группы — число подкатегорий; в разделе «Ещё» — число счетов, мест, групп и подкатегорий |
| FR-PAY-08 | В справочнике мест — отбор по набранным буквам названия, как FR-CAT-12. Это не поиск по операциям |

## Балансы и главный экран

| FR-BAL-01 | Баланс счёта равен начальному остатку плюс доходы, минус расходы, минус исходящие переводы, плюс входящие переводы. Учитываются все неудалённые операции без ограничения по дате (ADR-0009, ADR-0010) |
|---|---|
| FR-BAL-02 | Главный экран группирует счета по валютам |
| FR-BAL-03 | Внутри каждой валюты отображается один подытог: доступно к тратам. В него входят счета без признака «скрытый»; скрытые показываются ниже группой «Накопления», без подытога. В валюте одних скрытых счетов подытога нет вовсе — он был бы всегда нулём |
| ~~FR-BAL-04~~ | Аннулировано. Подытог накоплений упразднён вместе с FR-BAL-03: скрытый счёт не должен попадать и в отдельную сумму. Номер сохранён и повторно не используется |
| FR-BAL-05 | Единая сумма по всем валютам не вычисляется и не отображается |
| FR-BAL-06 | Отрицательный баланс допустим и не сопровождается предупреждением |
| FR-BAL-07 | Первый запуск без счетов: главный экран показывает приглашение создать счёт вместо списка. Пока счетов нет, кнопки операции на главном экране нет; форма, открытая из списка операций или ярлыком, ведёт к заведению счёта (FR-TRX-06) |

## Лента операций

| FR-LED-01 | Просмотр операций по выбранному счёту |
|---|---|
| FR-LED-02 | Порядок — от новых к старым. Внутри одной даты — по `created_at_utc` убывающе; при равных значениях ничья разбивается ключом (ADR-0002) |
| FR-LED-03 | Перевод отображается в ленте обоих задействованных счетов с корректным знаком и суммой в валюте соответствующего счёта. Итог дня ленты счёта считается в его валюте и включает обе стороны переводов |
| FR-LED-04 | Загрузка ленты выполняется постранично |
| FR-LED-05 | Общая лента по всем счетам показывает перевод одной строкой — со стороны счёта списания. Итог дня считается в рублях по счетам без признака «скрытый». Перевод входит в него как расход счёта списания, только если счёт зачисления в итог не входит — валютный или скрытый; перевод между двумя учитываемыми счетами итог не меняет, перевод со счёта вне итога — тоже. Строки по счетам в других валютах в ленте видны, но в итог не входят (FR-BAL-05, ADR-0004) |
| FR-LED-06 | Лента счёта без операций показывает строку начального остатка с датой открытия и приглашение добавить операцию |
| FR-LED-07 | Кнопка «+» ленты уходит за нижний край, пока ленту листают вниз, и возвращается при прокрутке вверх, у начала ленты и при возврате на экран: она закрывала сумму последней видимой строки |
| FR-LED-08 | Удаление из ленты — общей и ленты счёта. Смахивание строки влево открывает «Удалить» для одной операции с тем же подтверждением, что в карточке (FR-TRX-05). Долгое нажатие на строке включает выделение: касание отмечает строки и снимает отметки, «Удалить» удаляет отмеченные одним подтверждением, которое называет их число и балансы счетов после. «Назад», крестик, смена вкладки и уход с экрана снимают выделение; снятая последняя отметка выключает его. Кнопка «+» при выделении спрятана |

## Отчёт

| FR-RPT-01 | Отчёт за календарный месяц. По умолчанию открывается текущий месяц, месяц переключается стрелками |
|---|---|
| FR-RPT-02 | Переключатель вида: расходы или доходы. По умолчанию расходы |
| FR-RPT-03 | Первый уровень — список групп выбранного вида с суммой и долей в процентах, по убыванию суммы |
| FR-RPT-04 | Второй уровень — подкатегории выбранной группы, тем же списком с суммами и долями |
| FR-RPT-05 | Третий уровень — операции выбранной подкатегории за тот же месяц |
| FR-RPT-06 | Суммы считаются в рублях по счетам без признака «скрытый». Операции по счетам в других валютах в отчёт не входят (ADR-0004) |
| FR-RPT-07 | Переводы в отчёт не входят: перемещение денег между своими счетами не расход и не доход |
| FR-RPT-08 | Категории с признаком исключения из отчётов не отображаются и в суммы не входят |
| FR-RPT-09 | Месяц без операций показывает пустое состояние, а не нулевой список. Если операции месяца есть, но в суммы не вошли (FR-RPT-06), пустое состояние называет это правило, а не советует сменить месяц |
| FR-RPT-10 | Строка третьего уровня открывает ту же карточку операции, что и лента; правка и удаление доступны оттуда, после сохранения суммы отчёта пересчитываются. Раз поиска нет, отчёт — второй способ найти операцию, если помнишь категорию и месяц |
| FR-RPT-11 | Операция вида, обратного виду своей группы, вычитается из итога строки, а не прибавляется к нему: возврат в расходной группе уменьшает её расход (FR-CAT-14). Порядок строк считается по сведённому итогу, и итог бывает отрицательным. Такая строка показывает сумму знаком и цветом обратного вида, без доли и полосы; доли остальных считаются от суммы строк с положительным итогом, а итог уровня остаётся настоящей суммой |

## Синхронизация — отложено

**Вне MVP.** Раздел сохранён вместе с [требованиями к обмену](06-sync-deferred.md); идентификаторы заняты и повторно не используются.

| ~~FR-SYN-01~~ | Запуск синхронизации вручную из настроек |
|---|---|
| ~~FR-SYN-02~~ | Отображение даты последнего успешного обмена, количества неотправленных изменений и текста последней ошибки |
| ~~FR-SYN-03~~ | Получение изменений с сервера по курсору и применение их локально |
| ~~FR-SYN-04~~ | Отправка накопленных локальных изменений |
| ~~FR-SYN-05~~ | Работа приложения не блокируется недоступностью сервера или ошибкой авторизации |

## Настройки

| FR-SET-01 | Часовой пояс определяется системой устройства с возможностью переопределения вручную |
|---|---|
| ~~FR-SET-02~~ | Отложено вместе с обменом: адрес сервера и токен доступа задаются в настройках |
| FR-SET-03 | Тема оформления: системная, светлая, тёмная. По умолчанию системная. Настройка локальная |
| FR-SET-04 | Экран «О программе»: версия приложения и номер схемы базы данных. На пустой базе — строка разового переноса из Wallet (ADR-0014), после переноса она пропадает |
