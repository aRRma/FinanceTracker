# Стартовый набор категорий

Правила инициализации базы при первом запуске: какие категории создаются и с какими метками. Обоснование состава — в [preset-rationale.md](../preset-rationale.md), данные — в [data/preset.json](../../data/preset.json). Идентификаторы: `SEED-*`.

| SEED-01 | Набор записывается локально при первом запуске без обращения к сети |
|---|---|
| SEED-02 | Ключи категорий стартового набора детерминированы: UUIDv5 от фиксированного пространства имён и устойчивого текстового ключа (ADR-0006) |
| SEED-03 | Значение `updated_at_utc` у строк стартового набора — фиксированная давняя метка, единая для всех устройств и версий (ADR-0006) |
| SEED-04 | Номер применённой версии стартового набора хранится локально. Повторное применение не выполняется никогда |
| SEED-05 | Расширение набора в новых версиях приложения не затрагивает существующие установки. Исключение — правка, нужная всем установкам: её приносит миграция (ADR-0006, ADR-0013) |
| SEED-06 | В каждой группе, кроме служебной, есть приёмник «Прочее» (в группах «Без категории» он называется как группа, SEED-10). Служебная группа одна и универсальная; в ней одна подкатегория «Разница», исключённая из отчётов |
| SEED-07 | Каждая категория стартового набора имеет заданный значок. Ключи значков фиксированы и не меняются между версиями |
| SEED-08 | Справочник мест при первом запуске пуст и наполняется по мере ввода операций |
| SEED-09 | Все расходные группы набора, кроме «Без категории» (SEED-10), универсальные (FR-CAT-14). Доходные группы остаются односторонними (ADR-0013) |
| SEED-10 | В набор входят две группы «Без категории» — расходная и доходная, не универсальные: неразобранный доход не должен вычитаться из неразобранного расхода. В каждой одна подкатегория-приёмник с тем же названием. Установленным базам их приносит миграция (SEED-05), кроме базы, где группа с таким именем того же вида уже есть |
