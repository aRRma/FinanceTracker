# Стартовый набор категорий

Правила инициализации базы при первом запуске: какие категории создаются и с какими метками. Обоснование состава — в [preset-rationale.md](../preset-rationale.md), данные — в [data/preset.json](../../data/preset.json). Идентификаторы: `SEED-*`.

| SEED-01 | Набор минимальный, записывается локально при первом запуске без обращения к сети |
|---|---|
| SEED-02 | Ключи категорий стартового набора детерминированы: UUIDv5 от фиксированного пространства имён и устойчивого текстового ключа (ADR-0006) |
| SEED-03 | Значение `updated_at_utc` у строк стартового набора — фиксированная давняя метка, единая для всех устройств и версий (ADR-0006) |
| SEED-04 | Номер применённой версии стартового набора хранится локально. Повторное применение не выполняется никогда |
| SEED-05 | Расширение набора в новых версиях приложения не затрагивает существующие установки |
| SEED-06 | В набор входят подкатегория «Прочее» для каждой группы и две служебные подкатегории «Разница» с признаком исключения из отчётов |
| SEED-07 | Каждая категория стартового набора имеет заданный значок. Ключи значков фиксированы и не меняются между версиями |
| SEED-08 | Справочник мест при первом запуске пуст и наполняется по мере ввода операций |

Почему ключи детерминированы, а метка времени давняя, и что было отвергнуто — в ADR-0006.
