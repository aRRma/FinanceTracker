# Границы и среда

Назначение продукта, что входит в MVP и что вынесено за него, требования к платформам. Идентификаторы: `SYS-*`.

## Назначение

Мобильное приложение для персонального учёта личных финансов: счета, категории расходов и доходов, операции, текущие балансы. Пользователь — один человек, использующий несколько собственных устройств.

## Ключевое свойство

Приложение работает полностью автономно. Источник правды — локальная база на устройстве, и в MVP она единственная: сети приложение не требует вовсе.

Обмен между устройствами отложен (ADR-0007). Когда он появится, сервер будет только хранилищем строк и бизнес-логики не получит. Поля схемы под обмен — ключи, метки времени, пометки удаления — заведены сразу (ADR-0003).

## Границы MVP

**Входит:** счета, двухуровневые категории, операции трёх видов, балансы, отчёт о расходах и доходах по группам за месяц.

**Не входит:** синхронизация между устройствами и сервер, теги, вложения, операции с датой в будущем, повторяющиеся операции, бюджеты, цели накопления, импорт из сторонних приложений, поиск и фильтры по операциям, экспорт для анализа (таблицы, CSV), блокировка приложения, iOS.

Отчёт вошёл в MVP: без ответа на вопрос «куда ушли деньги» учёт операций не окупает усилий на ввод (ADR-0007).

**Исключения из «не входит», добавленные после MVP:** выгрузка всей базы в файл и восстановление из неё — для переноса на другой телефон и переустановки (ADR-0015); экспортом для анализа она не является — файл читает только само приложение. Разовый перенос истории из Wallet — не функция импорта: он идёт на рабочей машине отдельной сборкой, а готовая база попадает в приложение восстановлением из выгрузки (ADR-0014).

## Платформы и среды

| SYS-01 | Клиентская платформа — Android 16 (API 36) и выше: `SupportedOSPlatformVersion` = 36, `TargetFramework` = `net10.0-android`. Приложение личное, охват старых версий не нужен |
|---|---|
| ~~SYS-02~~ | Отложено вместе с обменом: серверная часть на Linux, при разработке на машине разработчика, в эксплуатации на выделенном VPS |
| ~~SYS-03~~ | Отложено вместе с обменом: адрес сервера задаётся конфигурацией, а не константой в коде |
| SYS-04 | Приложение полностью работоспособно без сети; к сети оно не обращается |
| ~~SYS-05~~ | Аннулировано как дубль NFR-15. Номер сохранён и повторно не используется |

## Системные ограничения

| SYS-06 | Расчётный объём данных — до 100 000 операций за весь срок использования |
| SYS-07 | Поддерживаемые валюты: RUB, USD, EUR. Конвертация между валютами не выполняется |
| ~~SYS-08~~ | Снято выгрузкой (ADR-0015). Было: резервной копии вне устройства в MVP нет |
