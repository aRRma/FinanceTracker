# План реализации

Границы MVP: одно устройство одного пользователя, без сети. Обмен с сервером отложен целиком — см. [docs/requirements/06-sync-deferred.md](docs/requirements/06-sync-deferred.md).

## Этап 0 · Доменное ядро

- [x] Роль категории (`role`) в схеме: без неё «Прочее» и служебные категории неотличимы — строкового ключа стартового набора в базе нет, а имя пользователь вправе изменить
- [x] Решение из пяти проектов по [docs/architecture.md](docs/architecture.md). Зависимости по [CLAUDE.md](CLAUDE.md), Android 16 (API 36). Пустой каркас MAUI собирается в Release — связка .NET 10 + MAUI + Android 16 проверена, риск из [docs/decisions.md](docs/decisions.md) закрыт
- [x] Тип денег: валюта в типе, сложение разных валют бросает исключение
- [x] Генерация ключей: обёртка над `Guid.CreateVersion7()` и своя реализация UUIDv5 — в .NET 10 её нет, а раскладка байтов `Guid` отличается от сетевого порядка, которого требует стандарт
- [x] Сущности с закрытыми конструкторами: фабричный `Create` с проверками, отдельный публичный путь восстановления без проверок и с предупреждающим комментарием
- [x] Доменные правила — все из [docs/requirements/02-domain.md](docs/requirements/02-domain.md), в коде названы членами перечисления `Invariant`
- [x] Межтабличные проверки. Где сущности хватает данных, правило осталось в ней, а факты подаются параметром: смена валюты и даты открытия живут в счёте. Отдельные типы понадобились троим: операция против счетов и категории, приёмник группы, уникальность имён. Домен остаётся без зависимостей
- [x] Тесты: на каждое правило срабатывание и пропуск корректного значения. Непокрытое правило роняет сборку — проверка сверяет пометки тестов и требования с перечислением `Invariant`
- [x] Проверка стартового набора переехала в `Finance.Docs.Tests`, её скрипт удалён
- [x] Проверки документации переехали туда же, скрипт проверки удалён. Свежесть прототипа проверяется отпечатками источников, которые проставляет `build_prototype.py`: вызывать Python из тестов нельзя, а сам сборщик остаётся

Готово, когда доменный проект не имеет внешних зависимостей и каждое доменное правило покрыто тестом.

## Этап 1 · Локальное приложение

- [x] Схема, миграции, резервная копия через `VACUUM INTO` перед накатом
- [x] Контекст через фабрику, режим WAL. Предкомпилированной модели нет: EF не собирает её при глобальном фильтре мягкого удаления, а фильтр важнее
- [x] Переопределение сохранения: `updated_at_utc` и события изменения. Очередь отправки — место оставлено, кода нет
- [x] Инициализация базы: запись стартового набора из [data/preset.json](data/preset.json) с фиксированной меткой времени
- [x] Слайсы счетов: карточка, закрытие, порядок перетаскиванием; главный экран с балансами по валютам
- [x] Слайс операций: запись, правка со сменой вида, мягкое удаление с подтверждением; место заводится из формы; последний счёт и сегодняшняя дата подставляются
- [x] Запросы балансов и ленты (`UNION ALL`, индексы по счёту и дате операции); лента постранично, итоги дней на стороне базы; SQL ленты счёта сверяется тестом
- [x] Слайс категорий: группа с приёмником «Прочее», подкатегория, перенос, удаление с переездом операций в приёмник одной транзакцией
- [x] Слайс мест: переименование, удаление без правки операций, счётчики использования и отбор по буквам
- [x] Экраны каркаса, ввода и ленты: балансы, общая лента, лента счёта, форма операции, справочник и карточка счёта
- [x] Экраны категорий: справочник с группировкой, карточки группы и подкатегории, подписи-счётчики в разделе «Ещё»
- [x] Экраны справочника мест и карточки места, строка «Места» в разделе «Ещё»
- [x] Слайс настроек: тема оформления, часовой пояс, «О программе». Экраны D-06, D-08, D-09 и строки в разделе «Ещё». Тема применяется при запуске и при выборе; возврат к системному поясу стирает настройку
- [x] Значки в интерфейсе: контуры Tabler в `data/icon-paths.json`, контрол `Icon` рисует их линией цветом темы — в справочнике категорий, в сетке выбора и в ленте операций
- [x] Клавиатура суммы по макету B-01: контрол `AmountKeypad`, правила набора в `AmountInput` (предел разрядов, одна запятая, действие только после числа), сохранение на самой клавиатуре и гаснет при незаконченной сумме
- [x] Темы: системная, светлая, тёмная; все цвета через токены; эталон палитр — переключатель темы в [docs/ui/mockups.html](docs/ui/mockups.html). Выбор хранится в базе рядом с прочими настройками, платформе доставляется делегатом из `AddFinance`
- [x] Навигация Shell с типизированной обёрткой, четыре вкладки: балансы, операции, отчёт, ещё
- [x] Индекс общей ленты: у индексов ленты счёта ведущая колонка — сам счёт, и сортировку по всем счетам они не обслуживают. План запроса сверяется тестом — по составу колонок этого не видно
- [x] Сбой в обработчике события больше не закрывает окно молча: обработчики синхронные и зовут `Guarded.Run`, `async void` остался в одном месте и с перехватом. Неудачное перечитывание экрана по чужой правке уходит событием, а не теряется в команде

Готово, когда приложение стоит на телефоне и используется по назначению.

## Этап 2 · Отчёт

- [x] Запросы агрегации по группам и подкатегориям за месяц, на стороне базы: `SUM` поверх копеек в `INTEGER`, порядок по убыванию задаёт `ORDER BY`. Новых индексов не понадобилось — план запроса сверяется тестом
- [x] Три уровня: группы, подкатегории, операции. Третий уровень — свой запрос, а не лента: в отчёт валютные операции не входят вовсе, а в ленте они видны, и общий запрос дал бы шапку, не сходящуюся со строками
- [x] Переключатель расходов и доходов, переключение месяца. Запрос отдаёт оба вида сразу, переключатель пересобирает список в памяти; стрелка «вперёд» гаснет на текущем месяце
- [x] Исключения: переводы, счета со «скрыть из расчётов», категории вне отчётов (флаг проверяется и на подкатегории, и на группе), валюты кроме рубля. Предикат «счета, входящие в суммы» один на итог дня ленты и на отчёт — `CountedAccounts`
- [x] Пустое состояние месяца без операций — своё для каждого вида: месяц с доходами, но без расходов, на вкладке расходов пуст

Готово, когда по отчёту видно, куда ушли деньги за месяц, и цифры сходятся с лентой.
