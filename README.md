# Личный трекер финансов

Android-приложение для учёта личных денег: счета, категории, операции, балансы и отчёт за месяц. Работает без сети — данные живут на телефоне; перенос на другой телефон — выгрузкой базы в файл.

**Стек:** C# 14, .NET 10, MAUI (Android 16+), EF Core и SQLite, xUnit.

## Сборка и тесты

```
dotnet test                 # домен, прикладной слой, проверки документации
dotnet build Finance.slnx   # всё решение, включая приложение
```

Готовые сборки — в Releases репозитория, их собирает GitHub Actions по тегу.
