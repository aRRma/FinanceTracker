# Выгрузка базы в файл и восстановление из него

Первый пункт Этапа 3 из [PLAN.md](../../PLAN.md): сохранить всю базу одним файлом и вернуть её
из файла — для переноса на другой телефон и для переустановки приложения. Без сервера и без
обмена: файл уносит сам пользователь (Google Диск, Telegram, почта).

Анализ проведён 2 октября 2026 в разговоре с пользователем и в тот же день пересмотрен по коду:
упрощён и исправлен порядок шагов восстановления (см. [SUMMARY.md](SUMMARY.md), «Что
пересмотрено»).

- [SUMMARY.md](SUMMARY.md) — решение и почему именно оно: варианты, отклонённое, факты кода,
  на которые решение опирается.
- [PLAN.md](PLAN.md) — шаги работ: файлы, тесты, документы, проверка в эмуляторе.

**Проверено в эмуляторе** (`pixel_7_clean`, отладочная сборка): выгрузка открывает «Поделиться»
с файлом `FinanceTracker-<дата>.db`; восстановление своей выгрузки поверх правленых данных —
подтверждение с числами обеих сторон, замена, перезапуск на главный экран, правка пропала;
чужой файл — «В этом файле нет данных трекера»; «Отмена» удаляет принятый файл; переустановка
(`adb uninstall`, `run`) и восстановление с пустого главного экрана — счета и настройки вернулись.
На релизной сборке (полный AOT, обрезка кода) пройдено то же: выгрузка, восстановление с
перезапуском, отказ на чужом файле. Первый запуск релизной сборки сразу после установки на
эмуляторе показал «не отвечает» и поднялся по «Подождать»; следующие холодные старты — без этого.
**Предупреждение с отсчётом (3 октября 2026, по просьбе пользователя):** замена непустой базы —
через красное предупреждение [D-11] с кнопкой, неактивной пять секунд; пустая база заменяется
без вопроса. «Дополнить данными из файла» отложено — причины в ADR-0015. По отзыву пользователя
предупреждение называет только удаляемое — сколько счетов и операций; ~~строка «В файле» и дата
последней операции~~ убраны. Проверено на
отладочной сборке: пустая база — сразу; с данными — отсчёт «(3)», нажатия во время него не
срабатывают, «назад» закрывает предупреждение и убирает принятый файл, после отсчёта замена и
перезапуск; тёмная тема.
Найдено и исправлено по ходу: выбор файла MAUI оставлял в кэше копию выбранной выгрузки —
страница удаляет её сразу после проверки.

## Вопросы перед началом

Решены рекомендациями 3 октября 2026; оставлены, чтобы было видно, из чего выбирали.

1. **Как отдавать файл: «Поделиться» или «Сохранить в…».** Рекомендация — «Поделиться»
   (встроенный `Share`, одна строка): в нём Google Диск, Telegram и почта, этого хватает и для
   переноса, и для переустановки. «Сохранить в…» — системный выбор папки, 40–60 строк своего
   кода под Android или новый пакет. Пользователю задан 2 октября 2026, ответа нет.
2. **Как назвать на экране.** В словаре «резервная копия» уже занята копией перед миграцией, а
   файл для переноса называется «выгрузка» ([CONTEXT.md](../../CONTEXT.md)). Рекомендация для
   экрана: «Сохранить данные в файл» и «Восстановить из файла»; в коде — `Export` и имя
   не `Restore`: оно уже занято путём восстановления сущности из базы (CONTEXT.md).
3. **Убирать ли перенос из Wallet.** Раньше в открытом списке плана было записано: слайс
   `Features/WalletImport` и карточка на «О программе» удаляются, когда появится выгрузка. Чистка
   плана 2 октября 2026 сняла и эту строку, а ADR-0014 теперь говорит «слайс остаётся» без
   срока. Перенос уже сделан, и выгрузка заменяет его как способ вернуть историю. Рекомендация
   — удалить отдельным шагом после проверки восстановления на телефоне; ADR-0014 остаётся, в нём
   дописывается, что слайс удалён.
4. **Где на экране.** Рекомендация — отдельная строка «Данные» в разделе «Ещё», экран с двумя
   строками: сохранить и восстановить. Альтернатива — две строки на «О программе», рядом с
   переносом из Wallet. Дополнительно стоит решить, нужна ли ссылка «Восстановить из файла» на
   пустом главном экране (C-06, «создайте счёт»): после переустановки человек попадает именно
   туда, а не в «Ещё».

## Что важно знать перед работой

- **Работа — в `master`** по решению пользователя (2 октября 2026), коммит только после его
  ревью.
- **Навыки — до первого действия:** `build` (миграции, сборка), `tests` (фикстуры, база), `maui`
  (экран), `texts` (строки и счётные формы), `emulator` (проверка).
- **Правка экрана — правка его макета** в той же задаче, затем `python tools/build_prototype.py`.
- **Проверка — на чистом эмуляторе** `pixel_7_clean`, перенос — между двумя эмуляторами или
  через переустановку: `adb uninstall`, затем `run` и восстановление.
- **Проверять на релизной сборке** тоже: восстановление трогает EF и миграции, а обрезка кода
  ломает механизмы на отражении.
- **Выгрузка — личные данные.** Файлы выгрузки с основного эмулятора и телефона — только в
  `artifacts/` этой папки, в документах — без цифр из них. Тесты — на синтетической базе.
