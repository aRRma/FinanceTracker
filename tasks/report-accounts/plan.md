# План работ: выбор счетов в отчёте

Решение и его обоснование — [summary.md](summary.md). Перед кодом — навыки по CLAUDE.md:
`tests` (запрос и тесты), `maui` (экран), `texts` (тексты), `emulator` (проверка), `build`.

## 1. Выбор и запрос

- [x] `ReportAccounts` в `Features/Report` — неизменяемое значение: «все активные» валюты
      (умолчание — рубли) либо набор ключей и валюта. Хранит его `ReportChoice` — один
      экземпляр на приложение (`AddSingleton` в `FinanceServices`), в памяти, перезапуск
      сбрасывает. Отметки, отказ на чужой валюте и нормализация (пустой — умолчание, равный
      активным своей валюты — «все активные» её) — в модели экрана выбора, на каждую отметку.
- [x] `CountedAccounts.Of` получает валюту; `FeedQuery` зовёт его с рублём — предикат один.
- [x] `IReportQuery` / `ReportQuery`: выбор параметром всех четырёх чтений; в `Counted`
      и `HasUncountedAsync` — свой набор (`keys.Contains(account.Key) && account.Currency == currency`)
      или `CountedAccounts.Of(context, currency)`.
- [x] Чтение счетов выбора для строки (`IReportAccountsQuery`): ключ, имя, цвет, значок,
      накопления, заблокирован — обычные, затем накопления, затем заблокированные; подпись
      и знаки строятся по нему.
- [x] Валюта из выбора: `ReportQuery` (два `Money.Restore`), `ReportViewModel`,
      `ReportGroupViewModel`, `ReportSubcategoryViewModel`, `ReportRowItem.ShareBase`.
- [x] Модели трёх уровней берут выбор из `ReportChoice`, а не из маршрута.

## 3. Тесты

- [x] Скрытый счёт в наборе — его операции в отчёте на всех трёх уровнях.
- [x] Набор долларовых счетов — суммы в долларах на всех трёх уровнях, рублёвые операции не входят.
- [x] По умолчанию отчёт прежний (`ReportTests` без изменений поведения).
      ~~Итог дня ленты не меняется при своём наборе~~ — отдельного теста нет: лента выбора
      не видит вовсе, а её итог сверяют прежние тесты ленты.
- [x] Выбор: чужая валюта отклонена; «Все активные» заменяет набор и меняет валюту; пустой —
      умолчание, равный активным своей валюты — «все активные» её; удалённый счёт отброшен.
- [x] «Все активные» евро подхватывает новый евровый счёт — правило, а не снимок.
- [x] Подпись строки: умолчание, все активные другой валюты, один счёт по имени, «N счетов»;
      удалённый счёт в число не входит.
- [x] Набор без счетов — и выбранный руками, и «все активные» другой валюты — возвращается
      к умолчанию.
- [x] План запроса с набором (`IN`) на всех трёх уровнях — без полного обхода операций
      (`QueryPlan.NoFullScan`).
- [x] Новые проверки ломаются нарочно в момент написания.
- ~~Перезапуск возвращает умолчание~~ — тест убран при аудите: он сравнивал две разные
  базы и не мог упасть. Выбор в памяти держится на том, что `ReportChoice` не знает
  о хранилище; сброс перезапуском проверен в эмуляторе.
