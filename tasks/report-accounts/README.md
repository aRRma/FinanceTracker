# Выбор счетов в отчёте

Пожелание пользователя 6 октября 2026: скрытые счета в отчёт не входят никогда, а расходы
по ним тоже интересно смотреть. На экране отчёта появляется выбор счетов: по умолчанию —
активные (как сейчас), остальные добавляются отметками. Счета разных валют вместе выбрать
нельзя — сообщение «Допускаются счета только с одинаковой валютой».

- [summary.md](summary.md) — разбор: как устроено сейчас, решение целиком, отклонённые варианты.
- [plan.md](plan.md) — порядок работ: код, тесты, документы, проверка в эмуляторе.
- variants.html — макет выбранного дизайна: строка счетов со знаками, экран «Счета отчёта»
  с «Все активные» у каждой валюты, правила, которые он задаёт. Собирается из
  variants.body.html и стилей макетов: `dotnet tasks/report-accounts/build_variants.cs`.

## Статус

коммита — итог в «Закрыто» [../../PLAN.md](../../PLAN.md), папка в архив вне репозитория.

Аудит 6 октября 2026: сверка кода с документами, ревью кода. Исправлено: нестабильный тест
(порядок ключей одной миллисекунды), «все активные» другой валюты без счетов теперь тоже
возвращаются к умолчанию, строка счетов не пересоздаёт знаки при том же наборе, лишний тип
знака убран, проверка плана запроса ловит и проход по индексу (`QueryPlan.NoFullScan`,
заодно в старых проверках отчёта и частых подкатегорий). Документы и макеты E-01–E-05 сверены.
