# Отчёты о сбоях

Открыта 6 октября 2026 по просьбе пользователя: нужна техническая диагностика, чтобы разбирать
сбои приложения на телефоне.

## Зачем

Сбой на телефоне сейчас не оставляет следа, который можно прочитать:
- перехваченный сбой пишется только в журнал Android — с телефона его не достать, а система затирает его за минуты;
- необработанные исключения .NET вне обработчиков не перехвачены вовсе — окно закрывается молча;
- нативное падение, падение внутри Java и зависание не ловит ничто. Так случилось разовое падение
  при смене темы (`VectorDrawable.setTint` в `libhwui`, PLAN.md проекта): повторись оно на телефоне —
  ни причины, ни экрана мы бы не узнали.

Задача заводит отчёты о сбоях на самом телефоне: файл, переживающий перезапуск, причины прошлых
завершений процесса от системы и короткий след действий перед сбоем. Отчёты смотрятся в
«О программе» и отправляются кнопкой «Поделиться»; после падения приложение о них не напоминает.

## Ограничения

- **Без сети.** Ни облачных сервисов сбоев, ни разрешения `INTERNET`: отчёты уходят только руками, через «Поделиться».
- **Никаких личных данных в отчётах:** ни сумм, ни имён счетов, групп и мест, ни заметок, ни ПИН-кода.
  Нарушенные доменные правила не пишутся — в их текстах бывают имена; текст прочих исключений — только у белого списка типов.
- **Отчёты — не в базе:** отдельный файл в папке приложения. В выгрузку базы не попадает, восстановление его не трогает.
- **Слои:** формат, запись, след и модель экрана — в `Finance.Application` (тестируются xUnit), в `Finance.App` —
  подключение обработчиков, обращение к `ActivityManager`, страница.
- Новая библиотека — только с согласия пользователя; план обходится без новых.

## Как продолжить в новой сессии

- Работа идёт в ветке `crash-journal-task` основной папки (отделена от `master`), ничего не закоммичено:
  коммит — после ревью пользователя.
- Перед кодом — навыки по CLAUDE.md: `build`, `tests`, `maui`, `texts`, `emulator` — каждый до первого действия своего рода.
- Продолжать с этапа 1. Факты API Android, на которых стоят этапы 2–4, проверены — раздел «Проверено на эмуляторе» в SUMMARY.md.
