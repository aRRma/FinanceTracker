# Виды тестов и инструменты тестирования

Открыта 6 октября 2026 по итогам аудита тестов.

## Зачем

Набор тестов сильный: покрытие строк около 96 %, ветвлений 87 %, случайных падений нет. Пробелов три:
- все тесты сумм построены на примерах из нескольких операций, придуманных руками;
- покрытие не говорит, ловят ли тесты ошибки: ручной мутант выжил при строке, покрытой на 100 %;
- у `Finance.App` и релизной сборки нет повторяемой проверки, только ручной обход в эмуляторе.

Задача закрывает эти пробелы. Новые виды тестов — сверка с простой моделью на случайных данных и сценарии эмулятора; новые инструменты — Stryker и покрытие изменённых строк.
