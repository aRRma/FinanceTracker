# Задачи

Долгая работа со своим состоянием живёт здесь — папкой на задачу: `README.md` с описанием,
этапами и статусом, подробности соседними `*.md`, скрипты задачи в `tools/`, данные
в `artifacts/` — эта папка отсечена в `.gitignore` и в репозиторий не попадает.
Инструменты всего проекта остаются в [../tools/](../tools/).

Статус задачи держится только в её `README.md`, в [../PLAN.md](../PLAN.md) — короткий блок
со ссылкой сюда: два списка галочек разъезжаются на первой же правке.

Закончилась задача — итог записывается в решение (ADR), в [../PLAN.md](../PLAN.md)
или в [../docs/decisions.md](../docs/decisions.md), а папка уходит в архив вне репозитория:
в материалах задачи бывают личные данные.

Открытых нет.

Итоги закрытых — в [../PLAN.md](../PLAN.md), раздел «Закрыто».
